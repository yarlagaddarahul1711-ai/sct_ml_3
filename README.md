# Image Classification using SVM

## Project Description
This project implements an image classification model using the Support Vector Machine (SVM) algorithm. The model classifies handwritten digit images from the sklearn digits dataset.

The project demonstrates:
- Image preprocessing
- SVM model training
- Prediction and evaluation
- Classification report generation
- Visualization of predictions

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

---

## Dataset Used
Sklearn Digits Dataset

The dataset contains:
- 8x8 grayscale handwritten digit images
- Labels from 0 to 9

---

## Algorithm Used
Support Vector Machine (SVM)

Kernel:
- Linear Kernel

---

## Steps Performed
1. Imported required libraries
2. Loaded the digits dataset
3. Saved dataset as CSV file
4. Split dataset into training and testing sets
5. Trained the SVM model
6. Generated predictions
7. Evaluated model accuracy
8. Displayed classification report
9. Generated confusion matrix
10. Visualized sample digit images

---

## Results
The SVM model achieved high classification accuracy on the testing dataset.

The project successfully demonstrates image classification using machine learning techniques.
